# Tabula — releases

Download assets for **Tabula**, a cross-platform desktop spreadsheet written in
pure Rust with a from-scratch immediate-mode GUI. It reads, creates, and edits
Excel `.xlsx` files, and runs Python expressions in cells.

This repository holds **built binaries only** — the source lives in a private
repository. Nothing here is meant to be cloned.

**[→ Download the latest release](https://github.com/alexiusacademia/tabula-release/releases/latest)**

| Platform | Asset | Notes |
| --- | --- | --- |
| macOS | `Tabula-<version>.pkg` | Installer package. Open it and follow the installer. |
| Windows | `tabula.exe` | Standalone executable — no installer. |

Linux builds aren't published yet.

Tabula is pre-release software under active development. It's a
[Syncster](https://syncster.dev) product; the landing page is at
[tabula.syncster.dev](https://tabula.syncster.dev).
